# Renty chat rules
- Sign sets and aliases are online-only: catalog metadata and prompts direct customers to the location-specific checkout; submitInquiry rejects them before validation or writes, including service packages and mixed requests, so model mistakes cannot send manual sign inquiries.
- Renty (Website-Chat) nur über supabase/functions/public-chat: Agent mit Katalogsuche (managed_products_public) und Werkzeug submit_rental_inquiry; Anfragen nur nach bestätigter Zusammenfassung, serverseitig validiert (renty-inquiry.ts, getestet), Quelle renty_chat, Mail an Standortpostfach, Testadressen @example.com gehen nur an das Testpostfach – damit keine erfundenen oder ungeprüften Anfragen im Portal landen.
- Renty read tools (search_tools, get_location_info, calculate_excavation/drying/power) live in renty-tools.ts, pure and tested from src/test/rentyTools.test.ts; they call _shared/calculators and _shared/tools-seo/public-locations so chat and website never compute or describe tools differently. Page context is path/location/product only, validated server-side.
