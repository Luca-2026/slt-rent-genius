# Protocol rules
- Signed handovers bind current offers and allocate inventory atomically through the delivery-note trigger; automatic AB dispatch reuses the existing sender with persisted signature evidence and provider idempotency. Document actions include protocols without opening the position editor.
- Protocol dialogs use exactly one scroll container (the dialog itself; step list sticky, footer sticky) so mouse wheel, touchpad and touch scroll everywhere; never nest a height-limited or overscroll-contained region inside, it traps scrolling.
- Protokollentwürfe je Mitarbeiter, Auftrag und Art mit Foto-Dateien in IndexedDB sichern und erst nach erfolgreichem Abschluss löschen – mobile Kamera und Browser-Neustart dürfen keine Erfassung vernichten.
- Measurements are individually optional per item; functions persist them in b2b_operating_hours_readings (legacy protocols also in protocol_data). Omit unset PDF values; wrap labels and values to the taller column to prevent condition-row overlap.
- Return extra charges use src/lib/returnCharges.ts: priceBasis marks new net inputs, converted once to the historic gross storage contract so invoices and deposit offsets stay consistent; unmarked drafts remain gross.
- Custom fill levels use the shared validated text-prefixed representation and label formatter so dropdown text survives drafts, storage and PDFs without permitting markup.
- Sauberkeit je Gerät (1 = sauber, verschmutzt ab Stufe 2) in protocol_data.items + b2b_operating_hours_readings.cleanliness; bei Rücknahme Pflicht, bei Übergabe optional. Reinigungssatz nur über CLEANING_RATE_PER_15_MIN (protocolShared) / CLEANING_UNIT_NET (returnCharges, getestet) – 20 € netto je 15 Min. Ausweisabgleich nur bei Übergabe; Ort/Zeit der Unterschrift in signed_place/signed_at.
